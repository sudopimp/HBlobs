# HBlobs

Make a living 2D blob from a recipe and drop it into a Hermes Agent profile.

This project is independent. It is not affiliated with or endorsed by Nous Research, Hermes Agent, or xAI. "Works with Hermes Agent" is nominative interoperability only.

Do not install custom packs with `hermes pets install <slug>` (gallery-only). Copy the pack into `$HERMES_HOME/pets/<slug>/` or use `/blob adopt` after installing the skill.

Requires Node. Atlas export may need a browser for rasterization.
