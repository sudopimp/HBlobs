# Eye-edge smoothness (2026-08-19)

Access date: 2026-08-19. Cursor-native research (WebSearch/WebFetch + 2 agents). No Grok Build.

## What was wrong

Idle eyes were a **48-point sampled stadium** (`EYE_N` + Catmull-Rom `pathFromRing`). At 400–800 CSS px that is ~11 samples per cap. Chord sagitta at `rx≈100` is ~1 CSS px — visible flats, read as “sharpened” on a dark-on-pink rim.

`shape-rendering="geometricPrecision"` was already set and is the **smooth** hint ([MDN](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Attribute/shape-rendering)). `crispEdges` / `optimizeSpeed` turn AA **off** in Blink ([`svg_shape_painter.cc`](https://raw.githubusercontent.com/chromium/chromium/main/third_party/blink/renderer/core/paint/svg_shape_painter.cc)).

## Fix

1. Hard C+L stadium is G1 but **not G2** — curvature jumps 1/r → 0 at the four cap↔side joins. That is the “red circle” kink ([Figma squircles](https://www.figma.com/blog/desperately-seeking-squircles/); [roomzer smoothed capsule](https://roomzer.dev/corner-smoothing-on-the-web/), fetched 2026-08-19). CSS `corner-shape: superellipse()` does not help: a 50% pill has no leftover short side.
2. Eyes use the Roomzer/Figma **smoothed capsule** (ξ = 0.6, iOS default): shoulders with κ=0 on the long side, trimmed circular arc, single cubic across each short cap so the apex does not cusp. Arcs become cubics, then pose-warp via `mapFn`.
3. Same-color `stroke` + `vector-effect="non-scaling-stroke"` + `feGaussianBlur` 0.5 uu.
4. Still `<path fill="var(--bg)">` — G-capsule forbids `<ellipse id="eye-l">`.

Gate: `gates/craft-eye-smooth.mjs` — `FAIL hard-join` on 4C+2L; twin 48-point ring → `FAIL sampled-ring`.
