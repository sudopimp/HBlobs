# Eye-edge smoothness (2026-08-19)

Access date: 2026-08-19. Cursor-native research (WebSearch/WebFetch + 2 agents). No Grok Build.

## What was wrong

Idle eyes were a **48-point sampled stadium** (`EYE_N` + Catmull-Rom `pathFromRing`). At 400–800 CSS px that is ~11 samples per cap. Chord sagitta at `rx≈100` is ~1 CSS px — visible flats, read as “sharpened” on a dark-on-pink rim.

`shape-rendering="geometricPrecision"` was already set and is the **smooth** hint ([MDN](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Attribute/shape-rendering)). `crispEdges` / `optimizeSpeed` turn AA **off** in Blink ([`svg_shape_painter.cc`](https://raw.githubusercontent.com/chromium/chromium/main/third_party/blink/renderer/core/paint/svg_shape_painter.cc)).

## Fix

1. Analytic stadium: 4 quarter-circle cubics (κ = 4/3 tan(π/8)) + 2 straight sides, then pose-warp the control points. `A` cannot survive `mapPoint` (non-linear). Spec for `A`: [SVG 2 paths](https://www.w3.org/TR/SVG2/paths.html).
2. Same-color `stroke` + `vector-effect="non-scaling-stroke"` so the fill’s AA fringe stays `--bg` ([MDN vector-effect](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Attribute/vector-effect); stroke is centered, [SVG 1.1 §3.6.1](https://www.w3.org/TR/SVG11/render.html)).
3. `feGaussianBlur` stdDeviation 0.5 user-units on the eye paths (outside the body clip, so the soft rim is not hard-cut). Scales with the blob; ~1 CSS px at studio size.
4. Still `<path fill="var(--bg)">` — G-capsule forbids `<ellipse id="eye-l">`.

Gate: `gates/craft-eye-smooth.mjs` (twin: 48-point ring → `FAIL sampled-ring`).
